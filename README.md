# Bank Branch Performance Dashboard

An interactive Power BI dashboard analyzing bank branch performance,deposits, loans, revenue, profit, customer growth, 
and NPA across regions.

## Dashboard Overview

The dashboard provides a consolidated view of key banking performance indicators and enables users to explore branch and 
regional performance through interactive filters and visualizations.

### Key Metrics

-   Total Branches
-   Total Deposits
-   Total Loans
-   Net Profit
-   Customer Growth %

### Key Visualizations

-   Net Profit by Branch
-   Total Deposits and Loans by Month
-   NPA % by Region
-   Total Revenue by Region
-   Net Profit and NPA % by City
-   Interactive filters for Region, Month, and Branch

## Tools Used

-   Power BI
-   Power Query
-   DAX
-   Excel

## Purpose

This project demonstrates the use of Power BI to transform banking data into an interactive dashboard for performance 
monitoring and data-driven decision-making.
